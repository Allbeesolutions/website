# AllBee adaptation note

The invitation experience for the three AllBee templates below was inspired by the open-source `dewanakl/undangan` project (MIT License): https://github.com/dewanakl/undangan

AllBee did not copy the original application code into these templates. The AllBee pages use their own HTML/CSS/JavaScript and integrate with the AllBee catalogue/order flow.

The upstream repository states that its visual assets are sourced from Pixabay. AllBee uses its own existing invitation imagery for these templates.
